# 공개 범위

## 포함한 내용

- 버전 관리 이력과 업무 산출물에서 확인한 담당 기능
- 시스템 구성과 기능 사이의 관계
- 구현 과정에서 고려한 상태, 중복, 장애와 운영 조건
- 실제 처리 방식을 설명하기 위해 독립적으로 작성한 예제와 테스트
- 공개 가능한 범위로 단순화한 부하 시험 시나리오

## 제외한 내용

- 회사 원본 소스와 원본 SQL
- 고객사·기관명과 내부 프로젝트 식별자
- 개인정보와 실제 시험·평가·VOC 데이터
- 서버 주소, 계정, 인증키, 토큰과 운영 설정
- 원본 문서, 화면 캡처와 데이터베이스 덤프

## 기여 범위 확인 방법

업무 산출물, 로컬 작업 사본과 버전 관리 작성자 이력을 교차 확인했습니다. 본인이 마지막으로 변경한 파일을 중심으로 담당 영역을 산정하되, 파일 수만으로 전체 기여도를 표현하지 않았습니다. 근거가 부족한 서비스는 담당 기능에서 제외하거나 문서에 별도로 표시했습니다.

공개 예제는 회사 클래스명과 테이블 구조를 복사하지 않았습니다. 실제로 해결한 문제와 검증 규칙만 남기고 모델, 인터페이스와 테스트를 새로 작성했습니다.
