# 참여 프로젝트와 담당 업무

경력기술서에 기재한 21개 항목을 프로젝트별로 정리하였습니다. 같은 고객사의 신규 개발과 후속 고도화는 별도 참여 업무로 표시하였습니다. 내부 개선·유지보수 항목은 여러 프로젝트와 겹치는 공통 업무이며 독립 구축 프로젝트 수로 합산하지 않았습니다.

담당 업무는 본인 경력 기록을 기준으로 작성하였습니다. 원본 코드·문서와 연결한 항목에는 상세 설명을 제공하고, 연결이 충분하지 않은 항목은 참여 업무 기록으로 구분하였습니다. 기간과 투입 인원은 구현 기여도나 단독 개발 범위의 증거로 사용하지 않았습니다.
